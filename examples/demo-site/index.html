On carrying pictures

Every photograph on this page is a few hundred kilobytes of colour that has to cross the network before you can see it. The stylesheet that lays the page out is a few kilobytes; the notes and comments below come from small JSON calls. A fair network gives them all an equal share and lets the small things wait behind the big ones. This page is served over HTTP4, where the browser grants the server permission to send, shortest job first, so the small things arrive first.

Open the panel in the corner to watch it happen: every resource, how it travelled, and the order it finished in.
